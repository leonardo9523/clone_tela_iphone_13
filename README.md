# Clone da Tela do iPhone 13

Este projeto recria visualmente a interface do iPhone 13 utilizando HTML e CSS.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/leonardo9523/clone_tela_iphone_13.git
   ```

2. Acesse a pasta do projeto:
   ```bash
   cd clone_tela_iphone_13
   ```

3. Abra o arquivo `index.html` no navegador.

## Sobre o projeto

Projeto final desenvolvido durante o curso **Udemy – HTML e CSS: O Início (incluindo 5 Projetos)**.
